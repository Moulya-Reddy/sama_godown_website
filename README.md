# Sama Sunitha Madhav Reddy Godown website

A responsive, static one-page website built with HTML, CSS and vanilla JavaScript. The photos supplied for the property are included in `assets/`.

## Preview locally

Open `index.html` in a browser. No build tools or paid services are required.

## Publish free with GitHub Pages

1. Create a public GitHub repository, for example `sama-godown-website`.
2. Upload all files and folders in this project (keep the `assets` folder structure).
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then Save.
6. GitHub will provide a free `https://YOUR-USERNAME.github.io/REPOSITORY/` website address after deployment.

## Before publishing

- Confirm the displayed phone number and full postal address.
- Confirm the Google Maps search result points to the correct property. The directions button currently uses a Google Maps search for the supplied business name and address.
- Add verified details such as total built-up area, clear height, power load, truck access, rent and availability only if you want them displayed. These have intentionally not been assumed.

The site uses Google Fonts when internet access is available; it falls back to system fonts if not.
